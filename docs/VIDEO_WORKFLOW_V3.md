# H3 视频工作流 V3

V3 新增两个节点，不迁移已有工作流或项目。

- **H3 视频裁切 V3**：整合定长裁切和智能分镜，按 24 fps 流式处理并将全部片段保存到裁切项目库，默认生成 MP4 预览。默认重叠显示为定长 22 帧、智能 0 帧；H3 帧数对齐只用于定长模式。裁切是独立的输出节点，不再选择一段通过连线输出；已有这类连线的工作流请改用 `H3 Segment Picker` 读取裁切片段库。
- **H3 长视频拼接 V3**：读取生成片段库，沿用单采和双采隔离、变体选择、无损直拷／重编码和慢放恢复。成片直接保存到 `output/h3_long/<项目>/` 并在面板预览，不需要接保存节点。镜头可拖动排序或用前移／后移，排除不删除原片段。面板显示所选采样版本实际可参与的镜头；成片的帧数、时长和报告来自后端结果。

两个 V3 节点都不提供连线输出。打开旧工作流时，这两个 V3 节点上遗留的输出口和连线会被移除；需要下游 `VIDEO` 连线时，可继续使用旧版 MiniMax H3 Clip Long Builder。

裁切库里的源视频片段不进入生成片段库。生成片段要先由 H3 片段保存节点归档，才会出现在拼接面板。

## 视频依赖

裁切通过 ComfyUI 的 Python 环境中的 PyAV 读取视频，不依赖 `ffprobe`。MP4 预览依赖 `ffmpeg`；缺失时仍会存储片段，面板会提示如何安装。长视频拼接用 `ffprobe` 测量视频参数。请在运行 ComfyUI 的机器安装包含 `ffmpeg` 和 `ffprobe` 的 FFmpeg，将两者所在的 `bin` 目录加入 `PATH`，在新终端确认 `ffmpeg -version` 和 `ffprobe -version` 都能运行，然后完整重启 ComfyUI。

## UI 约定

沿用「H3 参考素材」的 `.ahr` 外壳、项目库浏览器、PrimeIcons 和工作流配色。两个 V3 节点与「H3 片段选择」共用列宽、间距和 16:9 封面规则；档位从左到右为特大、大、中，未保存档位时默认大卡片。镜头卡片按成片序号排列，左右箭头调整相邻顺序，拖拽时以卡片侧边标出插入位置；点击封面直接播放当前拼接版本。素材等比完整展示；刷新、切换模式和卡片档位不改变节点尺寸。成片播放器作为同一面板的内容，不额外增加第二个弹性 DOM widget。

镜头卡片显示归档记录的「首段」或「衍生自」；未记录来源的旧素材不视为首段。媒体预览窗口按视口和视频比例适配，加载失败可以在窗口内重试。

裁切面板的长路径和片段标题可换行；项目和源视频下拉在当前值被截断时显示完整名称。裁切结果和预览警告位于片段卡片上方。

## 启用

部署 Python 与 `web/long_video/video_v3*` 文件后，完整重启 ComfyUI 后端并刷新网页。新旧节点可以在同一张画布里共存。
